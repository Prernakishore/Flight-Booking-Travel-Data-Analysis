# ✈️ Flight Booking & Travel Data Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing flight booking and travel data using Microsoft Power BI. An interactive dashboard was developed to explore booking trends, airline-wise ticket revenue, passenger preferences and payment behaviour.

The dashboard provides a consolidated view of key performance indicators (KPIs) and business metrics to support data-driven analysis.

## 🎯 Project Objectives

- Analyze overall flight booking performance.
- Compare ticket revenue across different airlines.
- Identify departure cities generating higher ticket revenue.
- Understand customer preferences across travel classes.
- Analyze payment methods based on booking count and ticket revenue.
- Explore passenger age patterns in relation to ticket revenue.

## 📊 Dashboard Highlights

### 1. Key Performance Indicators
- Total Bookings
- Total Ticket Revenue
- Average Passenger Age
- Total Distance Travelled
- Average Flight Duration
- Average Ticket Price

### 2. Airline Performance Analysis
Compared ticket revenue across airlines to identify the highest revenue contributors.

### 3. Departure City Analysis
Analyzed ticket revenue across different departure cities.

### 4. Travel Class Analysis
Compared booking distribution across Economy, Business, First Class and Premium Economy.

### 5. Payment Method Analysis
Used a Treemap and Donut Chart to examine payment preferences and revenue contributions.

### 6. Passenger Age Analysis
Explored ticket revenue across different passenger age groups.
